# Camera Calibration Consumer Guide for AI Agents & Downstream Programs

This document instructs agents, autonomous services, and external programs on how to discover, consume, and apply camera calibration profiles generated by `calibrator`.

---

## 1. Quick Integration

Import the loader module directly from the `calibrator` package:

```python
from calibrator import load_calibration, list_calibrations
import cv2

# Load by camera profile name (auto-checks output/<name>)
calib = load_calibration("astra720b")

# Load and verify or filter by Stream Type (e.g. 'RGB / Color', 'Depth', 'Infrared')
calib_rgb = load_calibration("realsense", stream_type="RGB")
calib_depth = load_calibration("realsense", stream_type="Depth")

# Or load directly from an exact file path (.npz, .json, or .yaml)
calib = load_calibration("/path/to/output/astra720b/camera_calibration.npz")
```


---

## 2. Reading Resolution, Camera Card, Source & Parameters

The `CameraCalibration` object provides standard properties for robotics and vision algorithms:

| Property | Type | Example / Description |
|---|---|---|
| `calib.camera_name` | `str` | `"astra720b"` |
| `calib.card_name` | `str` | `"Intel(R) RealSense(TM) Depth Ca"`, `"Astrap: Astrap"` |
| `calib.device_node` | `str` | `"/dev/video4"`, `"/dev/video8"` |
| `calib.stream_type` | `str` | `"RGB / Color"`, `"Color (MJPEG)"`, `"Infrared / Greyscale"` |
| `calib.resolution` | `Tuple[int, int]` | `(1280, 720)` -> `(width, height)` |
| `calib.resolution_str` | `str` | `"1280x720"` |
| `calib.width`, `calib.height` | `int`, `int` | `1280`, `720` |
| `calib.npz_path` | `Path` | Direct path to `.npz` archive |
| `calib.source_path` | `Path` | Resolved file path to `.npz` / `.json` |
| `calib.rms_error` | `float` | Mean reprojection error (e.g. `0.2870` px) |
| `calib.K` or `calib.camera_matrix` | `np.ndarray (3, 3)` | Camera intrinsic matrix |
| `calib.D` or `calib.dist_coeffs` | `np.ndarray (N,)` | Radial/tangential distortion parameters |
| `calib.fx`, `calib.fy` | `float`, `float` | Focal lengths in pixel units |
| `calib.cx`, `calib.cy` | `float`, `float` | Optical center coordinates |

## 3. Auto-Connecting to Camera Without Specifying Device Node

Downstream programs do not need to hardcode `/dev/video*` numbers (which change across USB re-plugs or reboots):

```python
from calibrator import load_calibration, find_stream_by_name

# Method A: Open stream directly from the calibrated object (auto-resolves current node)
calib = load_calibration("astra720b")
cap, (w, h) = calib.open_stream()

# Method B: Search camera stream by card name or type
stream = find_stream_by_name("realsense rgb")       # auto-detects current node (e.g. /dev/video9)
stream = find_stream_by_name("astrap")              # auto-detects current node (e.g. /dev/video2)
stream = find_stream_by_name("realsense infrared")  # auto-detects current node (e.g. /dev/video6)
```

### Syncing Device Nodes After Re-plugging / Using USB Hubs

Whenever cameras are unplugged, reconnected to a different USB port, or plugged through a USB hub:

```bash
# Run the sync CLI tool:
python sync_devices.py

# Or preview without making changes:
python sync_devices.py --dry-run
```

Or programmatically in Python:

```python
from calibrator import sync_device_nodes

results = sync_device_nodes()
```

## 3. Real-Time Undistortion Loop

For live video streaming, V4L2 capture, or OpenCV processing:

```python
import cv2
from calibrator import load_calibration

calib = load_calibration("astra720b")

cap = cv2.VideoCapture("/dev/video0")
cap.set(cv2.CAP_PROP_FRAME_WIDTH, calib.width)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, calib.height)

while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        break

    # Undistorts with internally cached cv2.remap lookup tables for maximum FPS
    undistorted_frame = calib.undistort(frame)

    # Downstream detection / tracking / SLAM
    process(undistorted_frame)
```

## 4. Discovering Available Calibrated Cameras

Agents can dynamically list all calibrated cameras in an output folder:

```python
from calibrator import list_calibrations

# Scans output/ directory for all calibrated profiles
profiles = list_calibrations("output")

for p in profiles:
    print(f"[{p.camera_name}] Res: {p.resolution_str} | RMS: {p.rms_error:.4f}px | File: {p.source_path}")
```

## 5. Standalone NumPy Consumption (Without `calibrator` Package)

If downstream agents cannot import the `calibrator` package, load the `.npz` archive directly using standard `numpy`:

```python
import numpy as np

data = np.load("output/astra720b/camera_calibration.npz")

K = data["camera_matrix"]   # 3x3 array (float64)
D = data["dist_coeffs"]     # 1x5 or 1x8 array (float64)
width, height = data["image_size"]  # [width, height]
rms_error = float(data["rms_error"])
```
